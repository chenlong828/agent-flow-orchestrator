# B1 用例清单

> 范围：仅 B1 的四类资产（Harness、工具、Skill、专家）。本文回答「B1 要处理哪些用例」，不是 API 设计；确认后再做组件规格与 REST 契约、表级数据库设计。

## 1 口径

- 用例（Use Case，UC）= 一个角色为达成一个目标完成的一次完整动作，不是单个 CRUD 端点。
- B1 的列表、详情、启停（Harness/Skill/专家）、删除包含在「维护某类资产」用例内；引用关系查询跨资产，单列。
- 种子、迁移、健康检查、测试基座是支撑任务，不是用例。
- 当前没有登录与鉴权；「资产管理员」是操作者角色，不对应账号体系。

## 2 用例总表

| ID | 用例 | 参与者 | 目标 | 领域对象 | 主要操作 | 验收出口 |
|---|---|---|---|---|---|---|
| `UC-B1-01` | 维护 Harness | 资产管理员 | 登记、修改、启停、删除 Harness | `OBJ-01`、`OBJ-02` | 列表/检索、详情、创建、更新、启停、删除 | 各操作可回读；名称唯一；被工具引用时不可删 |
| `UC-B1-02` | 维护工具 | 资产管理员 | 登记、修改、删除工具 | `OBJ-03`、`OBJ-04`、`OBJ-01` | 列表/检索、详情、创建、更新（参数整体替换）、删除 | 工具归属 Harness；参数有序；被专家引用时不可删 |
| `UC-B1-03` | 维护 Skill | 资产管理员 | 登记、修改、启停、删除 Skill | `OBJ-05`～`OBJ-11` | 列表/检索、详情、创建、更新五章、启停、删除 | 五章齐全；版本服务端递增；被专家引用时不可删 |
| `UC-B1-04` | 维护专家 | 资产管理员 | 登记、修改、启停、删除专家 | `OBJ-12`、`OBJ-13`、`OBJ-16`（读 `OBJ-03`/`OBJ-06`） | 列表/检索、详情、创建、更新五区、启停、删除 | 五区完整；颜色/角色合法；B1 无引用方时允许删除 |

## 3 用例卡

### 3.1 `UC-B1-01` 维护 Harness

- **前置**：数据库可用；操作者在本机使用管理 API。
- **主流程**：
  1. 列出 Harness，可按名称、类型、启停状态筛选。
  2. 打开详情，查看地址、接入方式、并发上限、排队策略、标签与健康状态。
  3. 创建或编辑；名称为全池唯一，标签有序，并发上限 ≥1。
  4. 启用/停用；只改 `enabled`，不级联改工具。
  5. 删除；若仍有工具引用，返回引用列表，不删除。
- **失败/边界**：重名 409；非法类型/接入方式/队列策略 400；`If-Match` 缺失 428、旧版本 409；被工具引用删除 409。
- **状态边界**：新 Harness `health=unknown`；B1 不提供心跳或「标记在线」入口；种子可带演示值但标注为夹具。
- **对象**：`OBJ-01`、`OBJ-02`。
- **验收**：各操作均有具体值断言；删除保护返回引用方；重启后数据仍在。

### 3.2 `UC-B1-02` 维护工具

- **前置**：已存在至少一个 Harness。
- **主流程**：
  1. 列出工具，可按名称、类型、状态、所属 Harness 筛选。
  2. 打开详情，查看调用信息、超时、参数与状态。
  3. 创建或编辑；必须归属一个 Harness；参数整体替换，按位置返回。
  4. 删除；若被专家引用，返回引用列表，不删除。
- **失败/边界**：重名 409；`harnessId` 不存在或非法 400/404；超时越界 400；参数键重复 400；被专家引用删除 409。
- **状态边界**：新工具 `status=unverified`；B1 不提供启停、调试、标记可用/不可用入口；`lastDebugAt` 不接受客户端写。
- **对象**：`OBJ-03`、`OBJ-04`、`OBJ-01`。
- **验收**：参数顺序、类型、Harness 归属可回读；删除保护正确；无启停入口。

### 3.3 `UC-B1-03` 维护 Skill

- **前置**：分类参考数据已就绪。
- **主流程**：
  1. 读取分类参考数据；列出 Skill，可按名称、分类、启停状态筛选。
  2. 打开详情，查看摘要、版本、五章、标签、触发词、踩坑与引用资料。
  3. 创建或编辑；五章必须齐全；标签/触发词/踩坑/引用按位置返回。
  4. 保存时服务端递增 minor 版本（如 `v1.0` → `v1.1`；minor 超过 9 时 `v1.9` → `v2.0`），客户端不能直接改。
  5. 启用/停用；删除前检查专家引用。
- **失败/边界**：重名 409；分类不存在 400/404；摘要超长 400；五章缺失 400；被专家引用删除 409。
- **对象**：`OBJ-05`～`OBJ-11`。
- **验收**：五章内容与顺序、版本递增、引用列表可回读；删除保护正确。

### 3.4 `UC-B1-04` 维护专家

- **前置**：无；Skill/工具可以稍后装配。
- **主流程**：
  1. 列出专家，可按名称、启停状态筛选。
  2. 打开详情，查看颜色、角色、五区、引用资料、Skill/工具装配。
  3. 创建或编辑；名称唯一，颜色为 `#RRGGBB`，角色非空。
  4. 启用/停用。
  5. 删除；B1 没有工作流节点引用，允许删除（若后续出现节点引用，再补保护）。
- **失败/边界**：重名 409；颜色/角色非法 400；`If-Match` 缺失 428、旧版本 409。
- **对象**：`OBJ-12`、`OBJ-13`、`OBJ-16`；读 `OBJ-03`/`OBJ-06`。
- **验收**：五区与引用资料可回读；启停生效；删除后关联子表与装配关系清理。

### 3.5 `UC-B1-05` 装配专家

- **前置**：专家已存在；Skill/工具可先不存在，保存时校验目标存在。
- **主流程**：
  1. 打开专家装配区，读取当前 Skill/工具有序列表。
  2. 选择 Skill 列表并排序，整体提交。
  3. 选择工具列表并排序，整体提交。
  4. 保存成功后回读顺序与专家 `revision`。
- **失败/边界**：目标不存在 400/404；重复目标 400；顺序位置冲突 400；旧 `revision` 409。
- **对象**：`OBJ-14`、`OBJ-15`；读 `OBJ-03`/`OBJ-06`。
- **验收**：顺序与集合完全一致；同一事务更新专家 `revision`；不会产生半套装配。

### 3.6 `UC-B1-06` 查询引用关系

- **前置**：资产与装配关系已存在。
- **主流程**：
  1. 在 Skill/工具详情查看「被哪些专家使用」。
  2. 在 Harness 详情查看「被哪些工具使用」。
  3. 删除前调用引用查询，决定是否继续。
- **失败/边界**：资产不存在 404；B1 只返回专家/工具引用，不返回工作流节点引用。
- **对象**：`OBJ-14`、`OBJ-15` + 四类资产。
- **验收**：引用方 ID、名称、类型、计数正确；与删除保护的引用列表同源。

## 4 横切规则

- **启停**：Harness、Skill、专家只改聚合根 `enabled`，不级联修改引用方；停用资产仍可被查询与展示。工具没有启停，状态只由后续调试适配器推进。
- **删除**：聚合根硬删除；子表级联删除；删除前检查引用，被引用返回 409 + 引用列表。
- **并发**：聚合根更新要求 `If-Match: "<revision>"`；缺失 428，不匹配 409。
- **计数**：`usedByCount` / `refCount` 查询时聚合，不落可写列。
- **状态诚实**：B1 不提供心跳、调试、验证、标记可用等入口；新数据保持 `unknown` / `unverified`。

## 5 与支撑任务的边界

以下不是用例，放在实施计划的支撑任务：

- 数据库连接、事务、迁移执行器、`schema_migrations`。
- HTTP 内核、错误模型、`/healthz`、分页/筛选通用参数。
- 测试库、种子夹具、架构测试、收口文档。
- 种子初始化：Harness 5、工具 10、Skill 12、专家 8，专家↔Skill 23、专家↔工具 23。

## 6 实现顺序与理由

1. `UC-B1-01` Harness：工具依赖 Harness。
2. `UC-B1-02` 工具：专家装配依赖工具。
3. `UC-B1-03` Skill：专家装配依赖 Skill。
4. `UC-B1-04` 专家：装配的前提。
5. `UC-B1-05` 装配：依赖专家、Skill、工具。
6. `UC-B1-06` 引用查询：依赖装配关系，且被删除保护复用。

列表/详情不单独建用例，随各维护用例交付；跨资产引用查询单列。

## 7 实施采用口径

用户 2026-10-24 直接要求按当前 spec 实现，以下按默认采用，不再逐项等待书面确认：

1. 用例粒度按「四类资产维护 + 装配 + 引用查询」六项；启停、删除并入对应维护用例。
2. 列表/详情随维护用例交付，不单独拆「浏览资产目录」。
3. 引用查询作为 `UC-B1-06` 独立用例，同时被删除保护复用。
4. 种子初始化作为工程支撑任务，不建业务用例。
5. 操作者按「本机资产管理员、无鉴权」处理；`X-Actor` 只用于显示。
