# AgentFlow 执行概念设计：结果

## 评审结论

评审通过。

[`concept-design.md`](concept-design.md) 作为后续设计启动的唯一主文档；原 `design-notes.md` 已删除，必要的设计决策结论并入该文档的 `3.2 设计决策补充（仅结论）`。

## 验收范围

本次验收的是概念与技术支撑点，不是完整设计，也不是实现：

- ACP 作为执行协议；
- 一个工作流实例对应一个 ACP 进程；
- 一个可执行节点/子任务对应一个 session；
- 节点之间只通过工作区传递信息；
- Skill 内容由控制面分发，工具在本地执行；
- ACP 并发与 Session 并发两档模型；
- 中断/失败后直接重跑；
- Bun + PostgreSQL 基础技术栈。

不包含：

- 数据库表、API、JSON 字段、固定路径、状态字符串等实现细节；
- 状态机、评审流程、工具目录、Skill 分层等完整设计；
- 生产容量、SLA、性能承诺；
- 远程 Harness、多机调度。
