# 用途

评审节点使用。把「审什么、怎么算过」落成结构化结论：**报告写进 `review.md`，结论通过 MCP 工具提交**。

## 步骤

1. 读取 `<task-space>/index.md` 与 `intent.md`，明确本次运行的目标与约束；索引里的项目文档与产物链接先读，再按需读证据。
2. 读取本阶段应审的产物（方案、代码说明、测试结论等），逐项对照目标核验。
3. 每条结论给出证据：文件路径、命令输出或测试结果；找不到证据的一律按不通过处理。
4. 把完整报告写进 `<task-space>/review.md`；回退第 N 轮写 `reviewN.md`，并在 `index.md` 的产物版本链串联；不覆盖上一轮（审什么、证据、结论、未决项）。
5. 调用工具列表里的 `mcp__agentflow__signal`（语义别名 `agentflow_signal`）提交结论：
   - `kind=review_verdict`
   - `verdict=pass` 或 `fail`
   - `reason`：通过依据或可执行的回退理由
   - `evidence`：证据列表（文件/命令/测试结果，可选）
   - 参数错误时按工具返回的错误修正后重试；不要在正文里另写一份 verdict。

## 应急呼人（确认通道）

评审节点同时挂 `mcp__agentflow__signal` 与 `mcp__agentflow__confirm`。只有在以下情形才调用 confirm：

- 已 accepted 需求/契约口径在文档里有两种合理解读，且选择直接改变 verdict；
- 设计/产物与上游 accepted 卡冲突，需要人确认哪边权威；
- 证据只能由人提供（例如「这个改动是否已获业务方同意」），缺它无法判定。

调用规则：

- 一次一个问题；`question` 短，`context` 写清现状、为什么现在必须决定、选项、推荐、影响、不回答的后果；
- 不要问「这个方案好不好」「该 pass 还是 fail」；不要用 confirm 代替 verdict、证据或回退；
- 人答复后任务用同一 session 续跑并注入 `[人工确认]`；把答复当输入，仍自行判断并提交 `review_verdict`；
- 无答复时保持等待，不自动 pass；取消后不写「已通过」；
- 每个 review 访问最多问 1 次；同一问题不重复问。

## 评审顺序

1. **需求-方案匹配**：需求是否可观察；验收是否服务价值；方案族是否比较过；约束/非目标是否标了来源。第一维不过，直接 fail 并写「回需求确认口径」。
2. **契约/边界/证据**：内部一致性、边界断言、证据可复跑。
3. **定级/确认门**：P 级与触发项、确认记录。

不要只审第一维之后的内部一致性；也不要让设计去满足一个用户没要求的自造契约。

## 判定标准

- `pass`：产物满足目标，证据齐全，没有未决的阻塞项。
- `fail`：存在缺失、与目标不符、证据不足，或留有必须修复的缺陷。
- `reason` 写「回哪个阶段、改什么」，不写情绪化评价；先写阻塞项清单（B1..Bn，每条一句「改什么」），控制在 300 字内；完整依据放 `review.md`。
- `fail` 必须引用任务出口或场景卡的具体条目（`T-xxxx` / `T-SCN-xxxx` / 文件行）；卡外新增的证据要求只能记建议。
- 发现「自造契约」或「自设非目标排除用户效果」：判 fail，理由写「回需求确认口径」，不判设计去满足。
- 回退重跑写 `reviewN.md`，不覆盖 `review.md`。
- 证据层级按任务出口与场景卡标注核对，不越级要求；证据分级见 `af-flow-rule` §1；确认与默认确认见 `auto-confirm`。

## 常见踩坑

- 工具可用却只在正文写结论：服务端不再解析消息 JSON，会按 `verdict_invalid` 判失败。
- 把工具公开名写成裸 `agentflow_signal` 去调用；模型应以工具列表显示的名字为准。
- `verdict` 用了 `passed`/`ok`/`true` 之类的值；工具会拒绝，按错误修正。
- 为了推进流程默认给 pass，却没有证据。
- 用「证据不够」判 fail，却指不出任务出口/场景卡的哪一条，或要求卡外的更高层级证据。
- 把评审判断交给 confirm 决定：confirm 只用于澄清口径/事实，verdict 仍由评审自己提交。
- 二轮评审重建整套探针；只应复核 delta 与最小复核集。
- 把上一轮 `review.md` 覆盖掉，丢失为什么退。
- 在自造契约内判 fail，让设计去修一个用户没要求的边界。
